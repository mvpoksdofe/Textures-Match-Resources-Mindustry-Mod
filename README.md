Silly Mindustry mod that changes textures of all serpulo (placeable) building so that you can tell what resources they had been built with. Purely visual. Currently does not change units nor anything on Erekir.

Note: Everything was painted in the most basic way using the mindustry palette, except for graphite and titanium colors, and maybe lead, but I can't tell, my bad. Most things will look worse, honestly, but I think the conveyors, some of the drills and some production buildings actually look fine/better.
